# Minimal Integration Example

The module has no runtime dependencies. Import it into a browser bundle or a Node.js project that supports ES modules.

```js
import { analyzeCode } from '../src/heuristic.js';

const source = `// Generated by an AI assistant\nconst customerIdentifier = input;`;
const report = analyzeCode(source);

for (const match of report.matches) {
  console.log(`${match.name}: lines ${match.indexes.join(', ')}`);
}
```

To change what is flagged, pass your own array of rule objects as the second argument. Each rule needs a `name`, a numeric `weight`, and a `matches(line, index, lines)` function that returns a boolean.

Before using the output in a workflow, present the matched lines and review them in context. The module supplies explainable signals rather than an authorship verdict.

See the live browser example at [ismycodeai.com](https://ismycodeai.com/).
