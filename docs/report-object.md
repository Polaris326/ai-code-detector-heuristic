# Review Report Object

`analyzeCode(source)` returns a small JavaScript object designed for a review UI or another programmatic workflow.

```js
{
  score: 47,
  lines: ['// Generated by an AI assistant', 'const customerIdentifier = input;'],
  matches: [
    {
      name: 'Explicit AI-tool attribution in a comment',
      weight: 34,
      indexes: [0]
    }
  ],
  flaggedLines: new Set([0])
}
```

- `score` is the sum of the matched rule weights, capped at 100.
- `lines` preserves the input after splitting it on line endings.
- `matches` identifies which configured rules matched and their zero-based line indexes.
- `flaggedLines` is a `Set` of the zero-based line indexes that matched at least one rule.

The score is deterministic for a given input and rule set. It does not express a detection accuracy rate or authorship probability.

The same report shape powers the example at [ismycodeai.com](https://ismycodeai.com/).
