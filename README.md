# AI Code Detector Heuristic

A small, dependency-free JavaScript module for exposing configured code-style signals in a reviewable report.

It scans a string of source code, returns matched rules and line numbers, and produces a score by summing configured rule weights with a cap of 100. The score is a deterministic heuristic. It is not a probability, an accuracy claim, or evidence of authorship.

## Use

```js
import { analyzeCode } from './src/heuristic.js';

const report = analyzeCode('// Generated by an AI assistant\nconst customerIdentifier = input;');
console.log(report.score);
console.log(report.matches);
```

## Output

`analyzeCode(source)` returns:

- `score`: sum of matched rule weights, capped at 100
- `lines`: the submitted source split into lines
- `matches`: rule names, weights, and matched line indexes
- `flaggedLines`: a set of zero-based line indexes

## Rules

The initial rules check explicit AI-tool attribution, explanatory comment patterns, long documentation-style comments, descriptive identifiers, repeated adjacent comments, and defensive error text. Adjust or replace the rules for your own review policy.
